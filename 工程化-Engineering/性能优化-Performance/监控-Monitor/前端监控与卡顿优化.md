# 前端监控与页面卡顿优化方案

---

## 一、监控系统设计（方案设计.md 精简整合）

### 1. 监控维度

- 性能监控（Web Vitals、TTI、FCP、API 响应、资源加载等）
- 错误监控（JS 错误、API 错误、资源加载失败、Promise 异常）
- 用户行为监控（PV、UV、会话时长、点击热力图等）

### 2. SDK 设计思路

- 自动采集性能、错误、行为等数据
- 批量上报，支持 sendBeacon，保证数据不丢失
- 支持采样、限流、脱敏、去重

### 3. 数据分析平台（以 Sentry 为例，简明流程）

1. 前端 SDK 采集数据
2. 服务端校验、脱敏、限流、去重
3. 消息队列缓冲
4. 后端聚合分析
5. 数据库高效存储
6. 前端平台可视化、告警

> 典型链路：前端 SDK → 服务端 → 消息队列 → 聚合分析 → 数据库 → 可视化平台

## 二、页面卡顿监测与优化方案

### 1. 性能监测方案

#### 1.1 长任务监控（Long Tasks）

- 监控主线程阻塞，任务超过 50ms 报警

#### 1.2 绘制时序指标（Paint Timing）

- 监控 FP、FCP，FCP 应在 2.5 秒内

#### 1.3 帧率监控（FPS）

- 监控帧率，低于 30fps 报警

#### 1.4 内存监控

- 监控内存使用率，及时发现泄漏

#### 1.5 Web Vitals 监控

- LCP（最大内容绘制）<2.5s
- CLS（布局偏移）<0.1
- FID（首次输入延迟）<100ms

#### 1.6 网络与资源性能

- 资源加载<1s，API 响应<500ms

#### 1.7 其他关键指标

- Navigation Timing（DNS、TCP、TTFB、DOM 解析）
- Element Timing（关键元素渲染时机）

## 三、常用监控代码片段

### 长任务监控

```javascript
const observeLongTasks = () => {
  if ("PerformanceObserver" in window) {
    const observer = new PerformanceObserver((list) => {
      list.getEntries().forEach((entry) => {
        if (entry.duration > 50) {
          console.warn("检测到长任务:", entry);
        }
      });
    });
    observer.observe({ entryTypes: ["longtask"] });
  }
};
```

### 帧率监控

```javascript
const monitorFrameRate = () => {
  let lastTime = performance.now();
  let frames = 0;
  let fps = 0;
  const calculateFPS = () => {
    frames++;
    const currentTime = performance.now();
    if (currentTime >= lastTime + 1000) {
      fps = frames;
      frames = 0;
      lastTime = currentTime;
      if (fps < 30) {
        console.warn("检测到可能的卡顿，当前帧率:", fps);
      }
    }
    requestAnimationFrame(calculateFPS);
  };
  calculateFPS();
};
```

### Web Vitals 监控

```javascript
const observeWebVitals = () => {
  if ("PerformanceObserver" in window) {
    // LCP
    const lcpObserver = new PerformanceObserver((list) => {
      const entries = list.getEntries();
      const lastEntry = entries[entries.length - 1];
      console.warn("LCP:", lastEntry);
    });
    lcpObserver.observe({ entryTypes: ["largest-contentful-paint"] });
    // CLS
    const clsObserver = new PerformanceObserver((list) => {
      let cumulativeScore = 0;
      list.getEntries().forEach((entry) => {
        cumulativeScore += entry.value;
      });
      if (cumulativeScore > 0.1) {
        console.warn("检测到较大的布局偏移:", cumulativeScore);
      }
    });
    clsObserver.observe({ entryTypes: ["layout-shift"] });
  }
};
```

### 网络与资源性能监控

```javascript
const observeNetworkPerformance = () => {
  const resourceObserver = new PerformanceObserver((list) => {
    list.getEntries().forEach((entry) => {
      if (entry.duration > 1000) {
        console.warn("资源加载较慢:", entry);
      }
    });
  });
  resourceObserver.observe({ entryTypes: ["resource"] });
  // API请求
  if (window.fetch) {
    const originalFetch = window.fetch;
    window.fetch = async (...args) => {
      const startTime = performance.now();
      try {
        const response = await originalFetch(...args);
        const duration = performance.now() - startTime;
        if (duration > 500) {
          console.warn("API请求较慢:", { url: args[0], duration });
        }
        return response;
      } catch (error) {
        console.error("API请求失败:", { url: args[0], error });
        throw error;
      }
    };
  }
};
```

## 四、优化建议（简要）

- 代码分割、懒加载，减少主线程压力
- 使用 Web Worker 处理重计算
- 图片/资源压缩，CDN 加速
- 预加载关键资源，合理使用缓存
- 事件节流/防抖，减少频繁操作
- 监控+告警+可视化，持续优化
