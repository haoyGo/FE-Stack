# 前端瀑布流实现完整指南

## 一、核心原理

### 1.1 什么是瀑布流？

瀑布流是一种**等宽不等高**的网页布局方式，特点：

- ✅ 所有卡片**宽度相同**
- ✅ 卡片**高度不同**（根据内容自适应）
- ✅ 卡片按**从上到下、从左到右**排列
- ✅ 新卡片总是插入到**当前最短的列**

**视觉效果示意**：

```
列1   列2   列3   列4
┌─┐  ┌─┐  ┌─┐  ┌─┐
│1│  │2│  │3│  │4│
│ │  └─┘  │ │  │ │
└─┘  ┌─┐  │ │  └─┘
     │5│  └─┘  ┌─┐
     │ │  ┌─┐  │6│
     └─┘  │7│  └─┘
          └─┘
```

### 1.2 核心算法原理（4 步走）

```javascript
// 初始状态
columnHeights = [0, 0, 0, 0];

// 1. 找最短列
const minHeight = Math.min(...columnHeights); // 找最小值
const minIndex = columnHeights.indexOf(minHeight); // 找索引

// 2. 计算位置
const left = minIndex * (itemWidth + gap); // 水平位置
const top = minHeight; // 垂直位置（从最短列当前高度开始）

// 3. 定位元素
item.style.left = `${left}px`;
item.style.top = `${top}px`;

// 4. 更新列高度
columnHeights[minIndex] += item.offsetHeight + gap;
```

**运行示例**（4 列，添加 5 个元素）：

```javascript
初始：[0, 0, 0, 0]
添加元素1(100px) → 插入列0 → [110, 0, 0, 0]
添加元素2(150px) → 插入列1 → [110, 160, 0, 0]
添加元素3(80px)  → 插入列2 → [110, 160, 90, 0]
添加元素4(130px) → 插入列3 → [110, 160, 90, 140]
添加元素5(120px) → 插入列2(最短) → [110, 160, 220, 140]
```

### 1.3 为什么插入最短列？

**目的**：让布局更紧凑、平衡

```
按顺序填充：总高 330px    插入最短列：总高 220px ✅
列1  列2  列3  列4        列1  列2  列3  列4
1    空   空   空         1    2    3    4
2    空   空   空         5    6    7    8
3    空   空   空         更平衡！
```

## 二、基础实现

### 2.1 完整代码（原生 JS）

```javascript
class Waterfall {
  constructor(container, options = {}) {
    this.container = container;
    this.columns = options.columns || 4; // 列数
    this.gap = options.gap || 10; // 间距
    this.items = [];
    this.columnHeights = new Array(this.columns).fill(0);
    this.itemWidth = 0;
    this.init();
  }

  init() {
    const containerWidth = this.container.offsetWidth;
    this.itemWidth =
      (containerWidth - (this.columns - 1) * this.gap) / this.columns;
    window.addEventListener(
      "resize",
      this.debounce(() => this.relayout(), 300)
    );
  }

  // 核心：添加元素
  addItem(item) {
    this.items.push(item);
    this.container.appendChild(item);

    const img = item.querySelector("img");
    if (img) {
      if (img.complete) {
        this.layoutItem(item);
      } else {
        img.onload = () => this.layoutItem(item);
      }
    } else {
      this.layoutItem(item);
    }
  }

  // 核心：布局单个元素
  layoutItem(item) {
    // 1. 找最短列（例：[100, 150, 80, 130] → 索引2）
    const minHeight = Math.min(...this.columnHeights);
    const minIndex = this.columnHeights.indexOf(minHeight);

    // 2. 计算位置
    const left = minIndex * (this.itemWidth + this.gap);
    const top = minHeight;

    // 3. 定位元素
    item.style.position = "absolute";
    item.style.width = `${this.itemWidth}px`;
    item.style.left = `${left}px`;
    item.style.top = `${top}px`;

    // 4. 更新列高度
    this.columnHeights[minIndex] += item.offsetHeight + this.gap;

    // 5. 更新容器高度
    const maxHeight = Math.max(...this.columnHeights);
    this.container.style.height = `${maxHeight}px`;
  }

  // 重新布局
  relayout() {
    this.columnHeights = new Array(this.columns).fill(0);
    const containerWidth = this.container.offsetWidth;
    this.itemWidth =
      (containerWidth - (this.columns - 1) * this.gap) / this.columns;
    this.items.forEach((item) => this.layoutItem(item));
  }

  // 防抖
  debounce(fn, delay) {
    let timer = null;
    return function (...args) {
      if (timer) clearTimeout(timer);
      timer = setTimeout(() => fn.apply(this, args), delay);
    };
  }
}
```

## 三、响应式适配

### 3.1 移动端适配

```javascript
class ResponsiveWaterfall extends Waterfall {
  constructor(container, options = {}) {
    const width = window.innerWidth;
    let columns = 4; // PC

    if (width < 576) columns = 2; // 手机
    else if (width < 768) columns = 3; // 平板

    super(container, { ...options, columns });

    // 监听屏幕旋转
    window.addEventListener("orientationchange", () => {
      setTimeout(() => this.updateColumns(), 300);
    });
  }

  updateColumns() {
    const width = window.innerWidth;
    let newColumns = 4;
    if (width < 576) newColumns = 2;
    else if (width < 768) newColumns = 3;

    if (newColumns !== this.columns) {
      this.columns = newColumns;
      this.relayout();
    }
  }
}
```

## 四、性能优化

### 4.1 图片懒加载

```javascript
const lazyLoad = () => {
  const images = document.querySelectorAll(".waterfall-item img[data-src]");

  const observer = new IntersectionObserver(
    (entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting) {
          const img = entry.target;
          img.src = img.dataset.src;
          img.removeAttribute("data-src");
          observer.unobserve(img);
        }
      });
    },
    { rootMargin: "100px" } // 提前100px加载
  );

  images.forEach((img) => observer.observe(img));
};
```

### 4.2 使用 transform 优化动画

```javascript
// ❌ 不好：触发重排（layout）
item.style.left = `${left}px`;
item.style.top = `${top}px`;

// ✅ 更好：只触发合成（composite）
item.style.transform = `translate(${left}px, ${top}px)`;
```

### 4.3 防抖滚动事件

```javascript
let scrollTimer = null;
window.addEventListener("scroll", () => {
  if (scrollTimer) clearTimeout(scrollTimer);
  scrollTimer = setTimeout(() => loadMore(), 200);
});
```

### 4.4 requestAnimationFrame 批量更新

```javascript
layoutItem(item) {
  requestAnimationFrame(() => {
    item.style.transform = `translate(${left}px, ${top}px)`;
  });
}
```

## 七、常见问题

| 问题        | 原因           | 解决方案                           |
| ----------- | -------------- | ---------------------------------- |
| 图片重叠    | 图片高度为 0   | `img.onload = () => this.layout()` |
| resize 错乱 | 未重新计算列宽 | 监听 resize 并 debounce            |
| 重复加载    | 未做防抖       | `loading` 标志位控制               |
| 滑动卡顿    | 渲染节点过多   | 虚拟滚动（>1000 条）               |
| 白屏        | 图片加载慢     | 懒加载 + 骨架屏                    |
