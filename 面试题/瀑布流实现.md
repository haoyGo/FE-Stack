# 前端瀑布流完整实现

## 一、原理详解

### 1. 什么是瀑布流？

瀑布流是一种**等宽不等高**的网页布局方式，特点是：

- 所有卡片**宽度相同**
- 卡片**高度不同**（根据内容自适应）
- 卡片按照**从上到下、从左到右**的顺序排列
- 新卡片总是插入到**当前最短的列**

**视觉效果**：

```
列1   列2   列3   列4
┌─┐  ┌─┐  ┌─┐  ┌─┐
│1│  │2│  │3│  │4│
│ │  └─┘  │ │  │ │
└─┘  ┌─┐  │ │  └─┘
     │5│  └─┘  ┌─┐
     │ │  ┌─┐  │6│
     └─┘  │7│  └─┘
          └─┘
```

### 2. 核心算法原理（4 步走）

```javascript
// 初始状态
columnHeights = [0, 0, 0, 0];

// 1. 找最短列
const minHeight = Math.min(...columnHeights); // 找最小值
const minIndex = columnHeights.indexOf(minHeight); // 找索引

// 2. 计算位置
const left = minIndex * (itemWidth + gap); // 水平位置
const top = minHeight; // 垂直位置（从最短列当前高度开始）

// 3. 定位元素
item.style.left = `${left}px`;
item.style.top = `${top}px`;

// 4. 更新列高度
columnHeights[minIndex] += item.offsetHeight + gap;
```

**运行示例**（4 列，添加 5 个元素）：

```javascript
初始：[0, 0, 0, 0]
添加元素1(100px) → 插入列0 → [110, 0, 0, 0]
添加元素2(150px) → 插入列1 → [110, 160, 0, 0]
添加元素3(80px)  → 插入列2 → [110, 160, 90, 0]
添加元素4(130px) → 插入列3 → [110, 160, 90, 140]
添加元素5(120px) → 插入列2(最短) → [110, 160, 220, 140]
```

### 3. 为什么插入最短列？

**目的**：让布局更紧凑、平衡

```
按顺序填充：总高 330px    插入最短列：总高 220px ✅
列1  列2  列3  列4        列1  列2  列3  列4
1    空   空   空         1    2    3    4
2    空   空   空         5    6    7    8
3    空   空   空         更平衡！
```

### 4. 三个关键点

**1. 绝对定位**：精确控制位置，元素互不影响

```javascript
item.style.position = "absolute";
item.style.left = `${left}px`;
item.style.top = `${top}px`;
```

**2. 等图片加载**：避免高度为 0 导致重叠

```javascript
img.onload = () => this.layoutItem(item);
```

**3. 设置容器高度**：绝对定位脱离文档流，容器会塌陷

```javascript
this.container.style.height = `${Math.max(...columnHeights)}px`;
```

## 二、核心算法（完整代码）

```javascript
class Waterfall {
  constructor(container, options = {}) {
    this.container = container;
    this.columns = options.columns || 4; // 列数
    this.gap = options.gap || 10; // 间距
    this.items = [];
    this.columnHeights = new Array(this.columns).fill(0);
    this.itemWidth = 0;
    this.init();
  }

  init() {
    const containerWidth = this.container.offsetWidth;
    this.itemWidth =
      (containerWidth - (this.columns - 1) * this.gap) / this.columns;
    window.addEventListener(
      "resize",
      this.debounce(() => this.relayout(), 300)
    );
  }

  // 核心：添加元素
  addItem(item) {
    this.items.push(item);
    this.container.appendChild(item);

    const img = item.querySelector("img");
    if (img) {
      if (img.complete) {
        this.layoutItem(item);
      } else {
        img.onload = () => this.layoutItem(item);
      }
    } else {
      this.layoutItem(item);
    }
  }

  // 核心：布局单个元素
  layoutItem(item) {
    // 1. 找最短列（例：[100, 150, 80, 130] → 索引2）
    const minHeight = Math.min(...this.columnHeights);
    const minIndex = this.columnHeights.indexOf(minHeight);

    // 2. 计算位置
    const left = minIndex * (this.itemWidth + this.gap);
    const top = minHeight;

    // 3. 定位元素
    item.style.position = "absolute";
    item.style.width = `${this.itemWidth}px`;
    item.style.left = `${left}px`;
    item.style.top = `${top}px`;

    // 4. 更新列高度
    this.columnHeights[minIndex] += item.offsetHeight + this.gap;

    // 5. 更新容器高度
    const maxHeight = Math.max(...this.columnHeights);
    this.container.style.height = `${maxHeight}px`;
  }

  // 重新布局
  relayout() {
    this.columnHeights = new Array(this.columns).fill(0);
    const containerWidth = this.container.offsetWidth;
    this.itemWidth =
      (containerWidth - (this.columns - 1) * this.gap) / this.columns;
    this.items.forEach((item) => this.layoutItem(item));
  }

  // 防抖
  debounce(fn, delay) {
    let timer = null;
    return function (...args) {
      if (timer) clearTimeout(timer);
      timer = setTimeout(() => fn.apply(this, args), delay);
    };
  }
}
```

## 三、响应式适配（移动端）

```javascript
class ResponsiveWaterfall extends Waterfall {
  constructor(container, options = {}) {
    const width = window.innerWidth;
    let columns = 4; // PC

    if (width < 576) columns = 2; // 手机
    else if (width < 768) columns = 3; // 平板

    super(container, { ...options, columns });

    window.addEventListener("orientationchange", () => {
      setTimeout(() => this.updateColumns(), 300);
    });
  }

  updateColumns() {
    const width = window.innerWidth;
    let newColumns = 4;
    if (width < 576) newColumns = 2;
    else if (width < 768) newColumns = 3;

    if (newColumns !== this.columns) {
      this.columns = newColumns;
      this.relayout();
    }
  }
}
```

## 四、虚拟滚动优化（大数据）

当数据 > 10000 时，使用虚拟滚动：

```javascript
class VirtualWaterfall {
  constructor(container, options = {}) {
    this.container = container;
    this.columns = options.columns || 4;
    this.gap = options.gap || 10;
    this.buffer = options.buffer || 200; // 缓冲区

    this.allData = [];
    this.itemsPosition = []; // 缓存所有元素位置
    this.renderedItems = new Map(); // 当前渲染的元素
    this.columnHeights = new Array(this.columns).fill(0);
  }

  // 预计算所有元素位置
  calculatePositions() {
    this.columnHeights.fill(0);
    this.itemsPosition = [];

    this.allData.forEach((item, index) => {
      const minHeight = Math.min(...this.columnHeights);
      const minIndex = this.columnHeights.indexOf(minHeight);

      const left = minIndex * (this.itemWidth + this.gap);
      const top = minHeight;
      const height = item.height || 300; // 预估高度

      this.itemsPosition.push({
        index,
        left,
        top,
        width: this.itemWidth,
        height,
      });
      this.columnHeights[minIndex] += height + this.gap;
    });
  }

  // 只渲染可见区域
  render() {
    const scrollTop = this.scrollContainer.scrollTop;
    const viewportHeight = this.scrollContainer.offsetHeight;

    const visibleTop = scrollTop - this.buffer;
    const visibleBottom = scrollTop + viewportHeight + this.buffer;

    // 找出可见元素
    const visibleItems = this.itemsPosition.filter((pos) => {
      return pos.top + pos.height >= visibleTop && pos.top <= visibleBottom;
    });

    // 移除不可见元素
    this.renderedItems.forEach((element, index) => {
      if (!visibleItems.find((item) => item.index === index)) {
        element.remove();
        this.renderedItems.delete(index);
      }
    });

    // 渲染新元素
    visibleItems.forEach((pos) => {
      if (!this.renderedItems.has(pos.index)) {
        const element = this.createItem(this.allData[pos.index], pos);
        this.content.appendChild(element);
        this.renderedItems.set(pos.index, element);
      }
    });
  }
}
```

## 五、性能优化

### 1. 图片懒加载

```javascript
const lazyLoad = () => {
  const images = document.querySelectorAll(".waterfall-item img[data-src]");

  const observer = new IntersectionObserver((entries) => {
    entries.forEach((entry) => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src;
        img.removeAttribute("data-src");
        observer.unobserve(img);
      }
    });
  });

  images.forEach((img) => observer.observe(img));
};
```

```javascript
// ❌ 不好：触发重排
```

## 八、总结

### 核心算法（一句话）

**就像玩俄罗斯方块，每次都把方块放到最低的地方。**

### 关键步骤

```javascript
1. 维护列高度数组 [0, 0, 0, 0]
2. 找最短列 Math.min(...columnHeights)
3. 计算位置 left = index * (width + gap), top = minHeight
4. 更新高度 columnHeights[index] += itemHeight + gap
5. 时间复杂度 O(n) (n个元素，m列很小可忽略)
```

### 完整执行流程

```
[0,0,0,0] → 添加100px → [110,0,0,0]
          → 添加150px → [110,160,0,0]
          → 添加80px  → [110,160,90,0]
          → 添加130px → [110,160,90,140]
          → 添加120px → [110,160,220,140] (插入索引2，最短列)
          容器高度 = max(110,160,220,140) = 220px
```

### 性能优化要点

- ✅ 图片懒加载（IntersectionObserver）
- ✅ 虚拟滚动（大数据 >10000）
- ✅ transform 代替 left/top（避免重排）
- ✅ 防抖滚动事件
- ✅ requestAnimationFrame

### 移动端适配

- ✅ 响应式列数（<576px: 2 列，<768px: 3 列，>=768px: 4 列）
- ✅ 触摸反馈（touchstart/touchend）
- ✅ 骨架屏占位
