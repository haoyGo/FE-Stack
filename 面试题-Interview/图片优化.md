## 一、图片格式选择

### 1. 格式对比

| 格式     | 压缩方式  | 透明度 | 动画 | 浏览器支持 | 压缩率               | 适用场景                   |
| -------- | --------- | ------ | ---- | ---------- | -------------------- | -------------------------- |
| **JPEG** | 有损      | ❌     | ❌   | 100%       | 中                   | 照片、复杂图像             |
| **PNG**  | 无损      | ✅     | ❌   | 100%       | 低                   | Logo、图标、透明图         |
| **WebP** | 有损/无损 | ✅     | ✅   | 96%+       | 高（30%+ vs JPEG）   | 通用                       |
| **AVIF** | 有损/无损 | ✅     | ✅   | 70%+       | 最高（50%+ vs JPEG） | 新项目首选                 |
| **SVG**  | 矢量      | ✅     | ✅   | 100%       | 极小                 | 图标、简单图形             |
| **GIF**  | 无损      | ✅     | ✅   | 100%       | 低                   | 简单动画（建议用视频替代） |

### 2. 格式选择决策树

```
开始
  ├─ 是矢量图？
  │   └─ 是 → SVG
  │
  ├─ 需要动画？
  │   ├─ 简单动画 → WebP/AVIF（降级 GIF）
  │   └─ 复杂动画 → MP4/WebM 视频
  │
  ├─ 需要透明度？
  │   ├─ 是 → WebP（降级 PNG）
  │   └─ 否 → WebP/AVIF（降级 JPEG）
  │
  └─ 照片/复杂图像
      └─ AVIF（降级 WebP，再降级 JPEG）
```

```typescript
        this.cache.set(format, supported);

   */
  async getBestFormat(): Promise<"avif" | "webp" | "jpeg"> {
    if (await this.supportsFormat("avif")) return "avif";
    if (await this.supportsFormat("webp")) return "webp";
    return "jpeg";
  }

  /**
   * 转换图片 URL 为最佳格式
   */
  async optimizeImageUrl(url: string): Promise<string> {
    const format = await this.getBestFormat();

    // 假设服务端支持格式转换
    if (format !== "jpeg") {
      return url.replace(/\.(jpg|jpeg|png)$/i, `.${format}`);
    }

    return url;
  }
}
```

### 2. Intersection Observer（推荐）

```typescript
// hooks/useLazyLoad.ts
import { useEffect, useRef, useState } from "react";

interface UseLazyLoadOptions {
  root?: Element | null;
  rootMargin?: string;
  threshold?: number | number[];
  triggerOnce?: boolean;
}

export function useLazyLoad<T extends HTMLElement>(
  options: UseLazyLoadOptions = {}
) {
  const {
    root = null,
    rootMargin = "50px",
    threshold = 0.01,
    triggerOnce = true,
  } = options;

  const ref = useRef<T>(null);
  const [isVisible, setIsVisible] = useState(false);
  const [hasBeenVisible, setHasBeenVisible] = useState(false);

  useEffect(() => {
    const element = ref.current;
    if (!element || hasBeenVisible) return;

    const observer = new IntersectionObserver(
      (entries) => {
        entries.forEach((entry) => {
          if (entry.isIntersecting) {
            setIsVisible(true);

            if (triggerOnce) {
              setHasBeenVisible(true);
              observer.unobserve(element);
            }
          } else if (!triggerOnce) {
            setIsVisible(false);
          }
        });
      },
      { root, rootMargin, threshold }
    );

    observer.observe(element);

    return () => {
      observer.disconnect();
    };
  }, [root, rootMargin, threshold, triggerOnce, hasBeenVisible]);

  return { ref, isVisible };
}

// 使用示例
function LazyImage({
  src,
  alt,
  ...props
}: React.ImgHTMLAttributes<HTMLImageElement>) {
  const { ref, isVisible } = useLazyLoad<HTMLDivElement>({
    rootMargin: "100px",
  });

  return (
    <div ref={ref} className="lazy-image-wrapper">
      {isVisible ? (
        <img src={src} alt={alt} {...props} />
      ) : (
        <div className="skeleton" style={{ aspectRatio: "16/9" }} />
      )}
    </div>
  );
}
```

### 3. 渐进式图片加载（Progressive Image）

```typescript
// components/ProgressiveImage.tsx
import { useState, useEffect } from "react";

interface ProgressiveImageProps {
  placeholderSrc: string; // 低质量占位图（10KB 以内）
  src: string; // 高质量图片
  alt: string;
  className?: string;
  onLoad?: () => void;
}

export function ProgressiveImage({
  placeholderSrc,
  src,
  alt,
  className = "",
  onLoad,
}: ProgressiveImageProps) {
  const [currentSrc, setCurrentSrc] = useState(placeholderSrc);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    // 预加载高质量图片
    const img = new Image();
    img.src = src;

    img.onload = () => {
      setCurrentSrc(src);
      setIsLoading(false);
      onLoad?.();
    };

    img.onerror = () => {
      console.error("Failed to load image:", src);
      setIsLoading(false);
    };

    return () => {
      img.onload = null;
      img.onerror = null;
    };
  }, [src, onLoad]);

  return (
    <img
      src={currentSrc}
      alt={alt}
      className={`progressive-image ${
        isLoading ? "loading" : "loaded"
      } ${className}`}
      style={{
        transition: "filter 0.3s ease",
        filter: isLoading ? "blur(20px)" : "none",
      }}
    />
  );
}

// 使用示例
<ProgressiveImage
  placeholderSrc="thumb-image.jpg"
  src="full-image.jpg"
  alt="Product"
/>;
```

```typescript
  );
```

```typescript
// components/ResponsiveImage.tsx
interface ImageSource {
  src: string;
  width: number;
  height: number;
}

interface ResponsiveImageProps {
  sources: {
    mobile?: ImageSource[];
    tablet?: ImageSource[];
    desktop?: ImageSource[];
  };
  fallback: string;
  alt: string;
  loading?: "lazy" | "eager";
  className?: string;
}

export function ResponsiveImage({
  sources,
  fallback,
  alt,
  loading = "lazy",
  className,
}: ResponsiveImageProps) {
  const generateSrcset = (imgs: ImageSource[]) => {
    return imgs.map((img) => `${img.src} ${img.width}w`).join(", ");
  };

  return (
    <picture>
      {/* 移动端 */}
      {sources.mobile && (
        <>
          <source
            media="(max-width: 767px)"
            srcSet={generateSrcset(sources.mobile)}
          />
        </>
      )}

      {/* 平板 */}
      {sources.tablet && (
        <source
          media="(min-width: 768px) and (max-width: 1023px)"
          srcSet={generateSrcset(sources.tablet)}
        />
      )}

      {/* 桌面 */}
      {sources.desktop && (
        <source
          media="(min-width: 1024px)"
          srcSet={generateSrcset(sources.desktop)}
        />
      )}

      {/* 降级 */}
      <img src={fallback} alt={alt} loading={loading} className={className} />
    </picture>
  );
}

// 使用示例
```

### 2. URL 参数化（以 Cloudinary 为例）

```typescript
// utils/cdn.ts
interface ImageTransformOptions {
  width?: number;
  height?: number;
  quality?: number;
  format?: "auto" | "webp" | "avif" | "jpg" | "png";
  crop?: "fill" | "fit" | "scale" | "crop";
  gravity?: "auto" | "face" | "center";
  blur?: number;
  sharpen?: boolean;
}

class ImageCDN {
  private baseUrl: string;

  constructor(baseUrl: string) {
    this.baseUrl = baseUrl;
  }

  /**
   * 生成优化后的图片 URL
   */
  transform(imagePath: string, options: ImageTransformOptions = {}): string {
    const {
      width,
      height,
      quality = 80,
      format = "auto",
      crop = "fill",
      gravity = "auto",
      blur,
      sharpen,
    } = options;

    const transformations = [];

    // 尺寸
    if (width) transformations.push(`w_${width}`);
    if (height) transformations.push(`h_${height}`);

    // 质量和格式
    transformations.push(`q_${quality}`);
    transformations.push(`f_${format}`);

    // 裁剪
    transformations.push(`c_${crop}`);
    if (gravity) transformations.push(`g_${gravity}`);

    // 特效
    if (blur) transformations.push(`e_blur:${blur}`);
    if (sharpen) transformations.push(`e_sharpen`);

    const transformStr = transformations.join(",");

    return `${this.baseUrl}/${transformStr}/${imagePath}`;
  }

  /**
   * 生成响应式图片 URLs
   */
  responsive(
    imagePath: string,
    sizes: number[],
    options: Omit<ImageTransformOptions, "width"> = {}
  ): Array<{ url: string; width: number }> {
    return sizes.map((width) => ({
      url: this.transform(imagePath, { ...options, width }),
      width,
    }));
  }
}

export const cdn = new ImageCDN(
  "https://res.cloudinary.com/your-cloud/image/upload"
);

// 使用示例
const productImage = cdn.transform("products/iphone-14.jpg", {
  width: 800,
  height: 600,
  quality: 85,
  format: "auto",
  crop: "fill",
});

// 响应式
const responsiveImages = cdn.responsive(
  "products/iphone-14.jpg",
  [400, 800, 1200, 1600],
  { quality: 85, format: "auto" }
);

// 生成 srcset
const srcset = responsiveImages
  .map(({ url, width }) => `${url} ${width}w`)
  .join(", ");
```

```typescript
// 根据网络状况动态调整质量
function getImageQuality(): number {
  const connection =
    (navigator as any).connection ||
    (navigator as any).mozConnection ||
    (navigator as any).webkitConnection;

  if (!connection) return 80; // 默认质量

  const effectiveType = connection.effectiveType;

  const qualityMap: Record<string, number> = {
    "slow-2g": 50,
    "2g": 60,
    "3g": 70,
    "4g": 85,
  };

  return qualityMap[effectiveType] || 80;
}
```

```typescript
// components/ImageWithFallback.tsx
import { useState } from "react";

interface ImageWithFallbackProps {
  src: string;
  fallbackSrc: string;
  alt: string;
  onError?: () => void;
}

export function ImageWithFallback({
  src,
  fallbackSrc,
  alt,
  onError,
  ...props
}: ImageWithFallbackProps) {
  const [imgSrc, setImgSrc] = useState(src);
  const [hasError, setHasError] = useState(false);

  const handleError = () => {
    if (!hasError) {
      setImgSrc(fallbackSrc);
      setHasError(true);
      onError?.();
    }
  };

  return <img src={imgSrc} alt={alt} onError={handleError} {...props} />;
}
```

```typescript
// directives/lazyLoad.ts
import type { DirectiveBinding } from "vue";

const lazyLoad = {
  mounted(el: HTMLImageElement, binding: DirectiveBinding) {
    const observer = new IntersectionObserver(
      (entries) => {
        entries.forEach((entry) => {
          if (entry.isIntersecting) {
            el.src = binding.value;
            observer.unobserve(el);
          }
        });
      },
      { rootMargin: "50px" }
    );

    observer.observe(el);

    // 存储 observer 以便清理
    (el as any)._lazyLoadObserver = observer;
  },

  unmounted(el: HTMLImageElement) {
    const observer = (el as any)._lazyLoadObserver;
    if (observer) {
      observer.disconnect();
    }
  },
};

export default lazyLoad;

// 使用
// <img v-lazy-load="imageUrl" alt="Product">
```

```typescript
// 监控图片加载性能
class ImagePerformanceMonitor {
  trackImageLoad(src: string) {
    const startTime = performance.now();

    return new Promise((resolve, reject) => {
      const img = new Image();

      img.onload = () => {
        const loadTime = performance.now() - startTime;

        // 上报数据
        this.report({
          type: "image-load",
          src,
          loadTime,
          size: this.getImageSize(img),
          timestamp: Date.now(),
        });

        resolve(img);
      };

      img.onerror = (error) => {
        this.report({
          type: "image-error",
          src,
          error: error.toString(),
          timestamp: Date.now(),
        });

        reject(error);
      };

      img.src = src;
    });
  }

  private getImageSize(img: HTMLImageElement): number {
    // 通过 Performance API 获取资源大小
    const resources = performance.getEntriesByType(
      "resource"
    ) as PerformanceResourceTiming[];
    const resource = resources.find((r) => r.name === img.src);

    return resource ? resource.transferSize : 0;
  }

  private report(data: any) {
    fetch("/api/analytics/image", {
      method: "POST",
      body: JSON.stringify(data),
      keepalive: true,
    });
  }
}

export const imageMonitor = new ImagePerformanceMonitor();
```

## 八、面试高频问题

### Q1：如何选择图片格式？

**答**：

1. **矢量图**：用 SVG（图标、Logo）
2. **照片**：AVIF（降级 WebP、JPEG）
3. **需要透明度**：WebP/PNG
4. **动画**：视频（MP4）优于 GIF

### Q2：如何实现图片懒加载？

**答**：

1. **原生**：`<img loading="lazy">`（简单场景）
2. **Intersection Observer**：精细控制（推荐）
3. **渐进式加载**：低质量占位图 → 高质量图
4. **虚拟滚动**：长列表场景

### Q3：如何优化图片加载性能？

**答**：

1. **格式优化**：WebP/AVIF
2. **尺寸优化**：响应式图片（srcset）
3. **压缩**：质量 80-85
4. **CDN**：全球加速
5. **懒加载**：按需加载
6. **预加载**：关键图片 preload
7. **占位符**：防止 CLS

### Q4：如何处理大量图片的页面？

**答**：

1. **虚拟滚动**：只渲染可见区域
2. **分页/无限滚动**：按需加载
3. **缩略图**：列表用小图，详情用大图
4. **WebP/AVIF**：现代格式
5. **CDN 缓存**：减少服务器压力

### Q5：如何避免图片导致的 CLS？

**答**：

1. **声明宽高**：`width`/`height` 属性
2. **aspect-ratio**：CSS 宽高比
3. **占位符**：骨架屏或低质量图
4. **容器预留空间**：`min-height`
